# قسم التعليم — الأدلة العملية والأسئلة والمصطلحات

> يُلصق بعد `_core.md` و`_terms.md`. اطلب **نوعاً واحداً** في الجلسة.
>
> ثلاثة مخططات صغيرة في ملف واحد عمداً: مجموعها اليوم 17 مدخلاً،
> وفصلها يعني ثلاثة ملفات يُفتح كلٌّ منها مرة في السنة فتتقادم.

---

أنت تكتب مادة تعليمية عملية لمسلم جديد. الخطاب مباشر وسهل، بلا اصطلاح غير مشروح.

## قاعدة تعمّ الأنواع الثلاثة

**المذهب يُذكر متى اختلف فيه العمل.** هذا القسم عمليّ لا مقارن، فلا تُفصّل الخلاف. إن كان الفعل متفقاً عليه فاذكره مطلقاً، وإن اختلف فاذكر الأشهر ثم أشر إلى الخلاف بعبارة قصيرة: «وعند المالكية كذا». ولا تجعل الدليل العملي جدول مقارنة مصغّراً.

**بلا مراجع.** هذا القسم لا يحمل أسانيد كتب، بخلاف المسائل. لا تُخرج حقل `sources`.

## النوع الأول: الدليل العملي `guides`

خطوات مرتّبة لعبادة: الوضوء، الصلاة، الغسل، التيمم.

| الحقل | الطول | الشكل |
|---|---|---|
| `title` | ٣–٦ كلمات | «صفة الوضوء»، «كيف تصلي» |
| `intro` | ٧–١٢ كلمة | جملة تمهيدية واحدة |
| `steps[].title` | ٢–٤ كلمات | فعل أمر: «اغسل وجهك» |
| `steps[].text` | ٨–١٧ كلمة | ما يُفعل بالضبط، بلا تعليل |

الخطوات **٥ إلى ٩**. رتّبها ترتيب الفعل لا ترتيب الأهمية.

```json
{
  "title": { "ar": "", "en": "", "ru": "", "es": "" },
  "intro": { "ar": "", "en": "", "ru": "", "es": "" },
  "steps": [
    {
      "title": { "ar": "", "en": "", "ru": "", "es": "" },
      "text":  { "ar": "", "en": "", "ru": "", "es": "" }
    }
  ]
}
```

**بلا `id` ولا `bookId`.**

## النوع الثاني: السؤال الشائع `faqs`

| الحقل | الطول | الشكل |
|---|---|---|
| `category` | كلمة أو كلمتان | من القائمة أدناه فقط |
| `question` | ٦–٩ كلمات | سؤال بصيغة السائل نفسه، ينتهي بـ ؟ |
| `answer` | ٢٠–٣٥ كلمة | جواب مباشر يبدأ بالحكم لا بالتمهيد |

**الأبواب المستعملة:** الدخول في الإسلام · الأركان · المذاهب · التوبة · اللغة · المفاهيم. إن لزم باب جديد فاذكره صراحةً بعد كتلة JSON.

هنا **محلّ الشبهات والاعتراضات**، لا في قسم العقيدة. والجواب عن الشبهة حجاجٌ لا برهان، فيكون منصفاً هادئاً بلا تهويل.

```json
{
  "category": { "ar": "", "en": "", "ru": "", "es": "" },
  "question": { "ar": "", "en": "", "ru": "", "es": "" },
  "answer":   { "ar": "", "en": "", "ru": "", "es": "" }
}
```

## النوع الثالث: المصطلح `glossary`

| الحقل | الطول | الشكل |
|---|---|---|
| `term` | كلمة واحدة | **مضبوطة بالشكل الكامل** في العربية: `حَدَث` |
| `definition` | ١٣–١٧ كلمة | تعريف جامع مانع، بلا مثال ولا استطراد |

الضبط الكامل شرط، لأن المصطلح يُعرض وحده فلا سياق يعين على قراءته.

الإنجليزية نقل صوتي ثم شرح: `Ḥadath (ritual impurity)`.

```json
{
  "term":       { "ar": "", "en": "", "ru": "", "es": "" },
  "definition": { "ar": "", "en": "", "ru": "", "es": "" }
}
```

# المسائل الفقهية

> يُلصق بعد `_core.md` و`_terms.md`. غيّر آخر ثلاثة أسطر فقط.
> الدفعة **خمس مسائل** لا عشر. جُرّب العشر فسُلّمت ثلاث.

---

أنت باحث في الفقه المقارن على المذاهب الأربعة.

## المهمة

اكتب مسائل فقهية، لكل مسألة حكم كل مذهب من المذاهب الأربعة مع مراجعه، بأربع لغات.

## المحتوى

**المعتمد في المذهب فقط.** لا خلاف داخلي ولا رواية مرجوحة ولا «وقيل» ولا «وفي رواية». حكم واحد صريح لكل مذهب.

**المسألة خلافية بين المذاهب.** ما تتفق فيه الأربعة حرفياً لا يصلح لموسوعة مقارنة.

**العبارة الفقهية المعروفة لا عبارة مركّبة.** وقع فعلاً: كُتب «حذاء إبهاميه لإذني حلمتيه» والصواب عند الحنفية «حتى يحاذي بإبهاميه شحمتي أذنيه». إن لم تحضرك العبارة الاصطلاحية بدقة فاكتب المعنى بعربية سليمة واضحة، ولا تلفّق اصطلاحاً.

**المذاهب الأربعة كلها إلزاماً.** نقص مذهب واحد يُبطل المسألة، ولا يُقبل «كالحنفية» ولا إحالة مذهب على آخر. لكل مذهب نصّه المستقل.

## المراجع

**كتابان إلى ثلاثة لكل مذهب**، من `_terms.md` وحده. الجدول **مغلق**: كتاب خارجه يُرفض آلياً، ولو كان معتمداً في المذهب.

الكتاب في المذهب الذي هو منه. «كشاف القناع» حنبلي، فلا يُنسب لغيره.

**الاسم مجرداً**: بلا مؤلف، بلا «و»، بلا فاصلة، بلا شرطة مائلة.

صحيح: `الشرح الكبير` ثم `حاشية الدسوقي` عنصرين منفصلين.
خطأ: `الشرح الكبير للدردير` · `زاد المستقنع / كشاف القناع` · `حاشية الدسوقي على الشرح الكبير`

لا تكرّر كتاباً داخل المذهب الواحد.

## الصياغة

| الحقل | الطول | الشكل |
|---|---|---|
| `title` | ٥–٩ كلمات | جملة اسمية، بلا علامة استفهام |
| `summary` | ٨–١٥ كلمة | **سؤال ينتهي بعلامة ؟** |
| `rulings[*].text` | ١٠–٢٢ كلمة | جملة واحدة تنتهي بنقطة |

**استثناء:** العبارة الاصطلاحية المشهورة تُترك كما هي وإن قصرت. «طاهر في نفسه غير مطهر لغيره» ستّ كلمات، وإطالتها تفسدها. الاستثناء للاصطلاح المعروف وحده، لا لاختصار من عندك.
| `chapter` | `باب كذا` | يبدأ بكلمة «باب»، بلا شرطة ولا تركيب مزدوج |

صحيح: `باب تكبيرة الإحرام`
خطأ: `صفة الصلاة - تكبيرة الإحرام والافتتاح`

```json
    "rulings": {
      "hanafi": {
        "text": { "ar": "", "en": "", "ru": "", "es": "" },
        "sources": [
          { "ar": "", "en": "", "ru": "", "es": "" },
          { "ar": "", "en": "", "ru": "", "es": "" }
        ]
      },
      "maliki":  { "text": {}, "sources": [] },
      "shafii":  { "text": {}, "sources": [] },
      "hanbali": { "text": {}, "sources": [] }
    }
  }
]
```

اكتب حقول المالكي والشافعي والحنبلي كاملةً كما في الحنفي. الاختصار أعلاه للعرض هنا فقط.

**بلا `id` ولا `ref` ولا `number` ولا `bookId`.**

## الطبيعة

المقالة ليست دليلاً ولا فتوى. هي **نصّ متّصل** يمشي بالقارئ من سؤال إلى فهم. النبرة هادئة تُخاطب العقل، بلا وعظ ولا استعلاء ولا مخاطبة الموافق أصلاً.

**لا تحوّل المقالة إلى أدلة.** إن وجدت نفسك تكتب مقدمات مرقّمة تُفضي إلى نتيجة، فقد خرجت عن النوع. البرهان المنظّم محلّه قسم العقيدة. المقالة تشرح وتربط وتُمهّد.

**لا تختلق نقلاً.** لا تنسب قولاً إلى عالم ولا تذكر إحصاءً ولا تاريخاً إلا وأنت واثق. النصّ التأملي أسلم من نقل مشكوك فيه.

**لا تمدح ولا تُدافع.** المقالة تشرح، ولا تُثبت فضل الإسلام ولا تردّ على خصم متوهَّم. تجنّب صيغ المدح: «سعة ورحمة»، «حيوية الشريعة وخلودها»، «صالح لكل زمان ومكان». ومثلها الدعاوى التاريخية المطلقة كـ«لم يكن الخلاف بين الأئمة مصدر نزاع قط» — بين المذاهب خصومات معروفة، والمبالغة تُفقد القارئَ الباحثَ ثقتَه في بقية المقالة أكثر مما تقنعه. اذكر الأمر كما هو ودع القارئ يحكم.

**آية أو حديثاً عند الحاجة فقط**، بلفظه الصحيح. الآية بين ﴿﴾. وإن شككت في اللفظ فاترك الاستشهاد.

## البنية

| الحقل | الطول | الشكل |
|---|---|---|
| `title` | ٣–٧ كلمات | اسمية، بلا علامة استفهام |
| `excerpt` | ١٢–١٨ كلمة | ما تعالجه المقالة، لا إعلان عنها |
| `sections` | ٤–٦ أقسام | الأول تمهيد والأخير خاتمة |
| `sections[].heading` | ٢–٥ كلمات | يُترك **فارغاً** في التمهيد وحده |
| `sections[].body` | ٤٠–١٣٠ كلمة | فقرات متّصلة، لا نقاط ولا ترقيم |

القسم الأول بلا عنوان لأنه يلي عنوان المقالة مباشرة فيكون العنوان تكراراً.

## الربط بالأدلة

`relatedRefs` مصفوفة **أرقام مرجعية** على صورة حرف ورقم: `["A9", "A11"]`.

**ليست معرّفات.** المعرّف `nubuwwa` والرقم المرجعي `A6`، والحقل يقبل الثاني وحده. إخراج المعرّف يكسر الرابط. خذ الرقم من القائمة في الذيل، وهي مكتوبة على صورة `A6 الحاجة إلى النبوة` — انسخ ما قبل المسافة.

**ولا تربط إلا بصلة حقيقية.** ثلاثة إلى خمسة متى وُجدت، و**`[]` فارغة متى لم توجد**. أدلة القسم كلها في وجود الخالق والنبوة والرسالة، فالمقالة في الفقه أو أصوله قد لا يكون لها فيها نظير. الفراغ أصدق من ربط مصطنع بأقرب دليل شكلاً.

## المخرجات

```json
{
  "title":   { "ar": "", "en": "", "ru": "", "es": "" },
  "excerpt": { "ar": "", "en": "", "ru": "", "es": "" },
  "relatedRefs": [],
  "sections": [
    {
      "heading": { "ar": "", "en": "", "ru": "", "es": "" },
      "body":    { "ar": "", "en": "", "ru": "", "es": "" }
    }
  ]
}
```

**بلا `id` ولا `ref`.** ومعرّف القسم `sections[].id` يسنده المستودع أيضاً.

## تحقق قبل الإرسال

- [ ] JSON صالح، بلا نصّ خارجه
- [ ] كل حقل له اللغات الأربع
- [ ] الحقول الروسية خالية من الحروف العربية
- [ ] ٤–٦ أقسام، والتمهيد وحده بعنوان فارغ في اللغات الثلاث
- [ ] كل `relatedRefs` **رقم مرجعي** `A#` لا معرّف، ومن القائمة المعطاة
- [ ] الربط بصلة حقيقية، أو `[]` فارغة
- [ ] لا مقدمات مرقّمة ولا صيغة برهان
- [ ] لا مدح ولا دفاع ولا دعوى تاريخية مطلقة
- [ ] لا نقل منسوب ولا إحصاء غير موثوق
- [ ] لا `id` ولا `ref`
- [ ] لا كلمات نائبة
